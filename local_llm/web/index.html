Comment ces suggestions sont vérifiées

Optimiser ce modèle

Choisissez un modèle dans le moteur direct pour le calibrer.

Un auxiliaire classique doit avoir exactement le même vocabulaire. Un auxiliaire spécialisé doit être déclaré pour les poids précis de la cible. L’app teste plusieurs méthodes et profondeurs de spéculation, puis vérifie chaque profil sur des prompts différents. Les têtes MTP intégrées sont aussi testées si elles sont présentes et prises en charge. Aucun modèle n’est téléchargé.

Le profil s’applique aux prochaines réponses de ce modèle. Changer les réglages peut recharger le moteur et vider son cache en mémoire ; le cache disque compatible peut le restaurer.

Cache des conversations · moteur direct

Jusqu’à 512 Mio sur disque, sans copier les modèles. Ces fichiers contiennent l’état de vos conversations et restent sur cet appareil. La restauration est utilisée seulement si elle est compatible et estimée plus rapide que le recalcul. Désactiver efface les fichiers du cache.

Comparaison sur ce PC : mêmes poids et même contexte. Une présélection réduit les essais. Discussion, code et contexte long : six workloads avec plusieurs longueurs d’entrée et jusqu’à 512 tokens de sortie, deux passages pour choisir, puis trois passages sur des prompts indépendants pour vérifier. Le gain affiché vient de cette vérification.

Les statistiques de la prochaine réponse apparaîtront ici.

Réglages de la discussion

        
      

      
      
      

        C’est une borne maximale, pas une longueur imposée. Le modèle s’arrête
        avant s’il a fini sa réponse.
      

      

        Pourquoi une borne si le modèle est local ?
        

          Même sans facturation, le modèle utilise du temps de calcul et de la
          mémoire. Cette borne évite une génération interminable et doit tenir
          dans son contexte. Un token est un morceau de texte, pas forcément un
          mot.
        

      

      

        
        

      

      
      

        À 0, le modèle privilégie sa réponse la plus probable. Une valeur plus
        élevée ajoute de la variation.
