Comment connecter LM Studio ?
  1. Ouvrez LM Studio sur ce PC.
  2. Ouvrez l’onglet Developer (icône terminal).
  3. Activez Start server, avec l’adresse indiquée ci-dessous. Le serveur doit rester sur localhost.
  4. Cliquez sur Actualiser ici. Les modèles apparaîtront dans la bibliothèque, même s’ils ne sont pas encore chargés.

http://127.0.0.1:1234

Si LM Studio exige un jeton, configurez LM_STUDIO_API_TOKEN au lancement de l’application.

Réglages de la discussion

C’est une borne maximale, pas une longueur imposée. Le modèle s’arrête avant s’il a fini sa réponse.

Pourquoi une borne si le modèle est local ?

Même sans facturation, le modèle utilise du temps de calcul et de la mémoire. Cette borne évite une génération interminable et doit tenir dans son contexte. Un token est un morceau de texte, pas forcément un mot.

À 0, le modèle privilégie sa réponse la plus probable. Une valeur plus élevée ajoute de la variation.
